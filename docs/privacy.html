Inbox Triage Privacy Policy

Effective date: 2026-11-20

What it accesses

Inbox Triage accesses Gmail only for the account owner who authorizes it. It uses the gmail.modify scope to read message metadata (sender, subject, date and labels) and message snippets, and to change labels or move messages to Trash.

How data is processed

Message content is classified on the owner's iPhone by Apple's on-device model. No Gmail data is sent to the developer or to any third party. Gmail data is not sold and is not used for advertising.

The optional review page (review.html on this site) receives a run's report only in the part of the link after #, which browsers do not send to the server. The page makes no network requests and stores nothing; its Submit button hands the owner's corrections back to the shortcut on the iPhone. The link stays in the owner's browser history until it is cleared.

Credentials

Credentials are stored only on the owner's device. The owner can revoke access at any time at https://myaccount.google.com/permissions.

Google API Services User Data Policy

Inbox Triage's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions can be raised through GitHub Issues.
